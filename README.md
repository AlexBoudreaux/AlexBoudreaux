## Work Projects

### Visual Diagram Generator (Patent Pending)
> Legacy business process mapping was manual and tedious. First approach using LLMs to generate XML directly failed badly - maybe 1 in 10 worked. Built a hybrid system instead: LLM handles understanding and reasoning (outputs JSON), Python handles deterministic syntax transformation (JSON to XML). Went from 10% to 99% reliability. Filed for patent.

**Tech:** `Python` `LLMs (Llama/Mistral)` `JSON→XML`

---

### Custom RAG for API Documentation
> Financial services company's support agents were spending hours searching through thousands of pages of API docs. Built custom RAG pipeline with specialized chunking for technical documentation, semantic search with reranking, and evaluation framework. Reduced answer time from hours to minutes. Got selected to demo it at their conference in Vegas.

**Tech:** `RAG` `Vector DB` `Semantic Search` `Reranking` `Evaluation Framework`

---

### Sales Intelligence Agent
> Built an agent that pulls AI news, competitor updates, and product documentation changes every morning. Uses Perplexity API and internal databases to generate a daily briefing. Saves about 4 hours a week and gives me better hooks for sales conversations. Still running it daily.

**Tech:** `Perplexity API` `Agent Orchestration` `Python`
